# Rule: Traceability Matrix Requirements (traceability-required)

## Directives
1. **Traceability Centralization**: Document prose in PRD, RFC, FDD, and ADRs must remain clean. Inline timestamps or source tags are prohibited in the document bodies.
2. **Central Matrix (`docs/TRACKER.md`)**: All requirements, architectural decisions, and component contracts MUST be mapped in `docs/TRACKER.md` to authoritative source code files and line numbers (`file.ext#Lnn`).
